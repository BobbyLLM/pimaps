# Data sources and provenance

Pi Maps does not commit regional bulk data to Git. The program is small; the
map/search/routing data is versioned separately and described by an edition
manifest.

For the official Western Australia v1.0.0 edition, the runtime consumes four
kinds of data.

| Artefact | Used for | Upstream/source |
|---|---|---|
| `map.pmtiles` | Vector map display | Protomaps build, extracted to the WA region |
| `search.sqlite` | Local names, addresses and POIs | Western Australia OpenStreetMap extract |
| `routing/segments/*.rd5` | BRouter road graph | BRouter `segments4`, derived from OSM |
| `wiki-pois.sqlite` | Map POI -> local article identity | WA OSM Wikipedia tags + pinned local ZIM |
| optional `.zim` | Local Wikipedia articles | Kiwix upstream |

## OpenStreetMap input

The public v1 manifest records the WA source identifier as `wa.osm.pbf`, a
source date of `2026-09-25T04:00:00Z`, replication sequence `123021`, and the
source file size used for the accepted build.

The original source URL and original PBF SHA-256 were **not retained** during
the build and are explicitly recorded as `UNKNOWN_NOT_RETAINED`. That is a
known provenance limitation of v1.0.0, not an invitation to reconstruct a URL
and present it as historical fact.

Future regional builds should retain both values.

OpenStreetMap data is © OpenStreetMap contributors and is subject to the ODbL.
See `NOTICE.md` for the project's attribution summary.

## PMTiles map

The repository's maintainer helper uses a dated Protomaps build as the source
and extracts a regional archive with the PMTiles CLI:

```text
https://build.protomaps.com/<SOURCE_DATE>.pmtiles
```

For the accepted WA bundle, the manifest records **Protomaps build 20260925**.
The generated map is zoom levels 0 through 15.

`scripts/setup-pmtiles.sh` is intentionally WA-only in v1. It expects a pinned
regional GeoJSON boundary and stages the output as `.next`, verifies it with the
PMTiles CLI, then promotes it and prints a SHA-256.

The exact historical boundary source is not encoded in the public v1 manifest.
For future builds, record it alongside the OSM/PMTiles provenance rather than
leaving that information in a maintainer shell history.

## Local search database

`scripts/build-search.py` filters the supplied OSM PBF with `osmium-tool`,
exports matching objects to GeoJSON sequence, and builds a fresh SQLite/FTS5
database.

It keeps source identity rather than flattening everything into anonymous
coordinates. Records include fields such as:

- `osm_type` and `osm_id`;
- feature class/subclass;
- title and address components;
- locality and postcode;
- canonical longitude/latitude;
- optional verified route-anchor identity and coordinates.

The builder writes to `<output>.next`, runs SQLite `integrity_check`, and only
then replaces the requested output.

The browser/search service does not fall back to an Internet geocoder. If the
local OSM-derived source does not contain a usable record, the result can
correctly be "not found".

## BRouter segments

The official segment list is in:

```text
brouter/segments-wa.txt
```

and the pinned digests are in:

```text
brouter/segments-wa.sha256
```

`scripts/fetch-brouter-segments.sh` downloads from BRouter's official
`segments4` service, verifies every checksum, and promotes each file from a
temporary `.next` name.

The exact upstream weekly snapshot date is not separately encoded in the v1
manifest; the 19 pinned SHA-256 values identify the accepted bytes.

BRouter code is MIT licensed; the routing data is derived from OpenStreetMap
and remains subject to the applicable OSM data terms.

## Wikipedia/Kiwix

FULL mode uses:

```text
wikipedia_en_all_mini_2026-06.zim
```

from Kiwix upstream. `editions/wa.json` pins its URL, exact size, and SHA-256.
The Pi Maps GitHub Release does not redistribute the ~12.5 GB ZIM.

`wiki-pois.sqlite` is generated by joining OSM features carrying English
Wikipedia tags to titles that can actually be resolved inside the chosen ZIM.
That lets the runtime stay local: the map can show Wikipedia-linked places and
fetch summaries/articles from Kiwix without calling Wikipedia.org.

See [wikipedia.md](wikipedia.md) for the runtime and builder details.
